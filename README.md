# 🏆 Sistema de Gerenciamento de Interclasse

[![Status](https://img.shields.io/badge/status-ativo-brightgreen)](https://github.com/seu-usuario/interclasse-manager)
[![Tecnologias](https://img.shields.io/badge/tecnologias-PHP%2C%20MySQL%2C%20CSS%20Puro-orange)](https://github.com/seu-usuario/interclasse-manager)
[![Licença](https://img.shields.io/badge/licença-MIT-green)](LICENSE)

## 🎯 Problema que Resolvemos

Na nossa escola do ensino médio, a organização dos jogos interclasse era um caos total: planilhas de Excel perdidas, horários marcados no quadro que eram apagados, resultados discutíveis e muita confusão. Este sistema nasceu da necessidade real de trazer ordem e justiça às competições entre as turmas, substituindo a bagunça por organização digital.

## ✨ Funcionalidades Principais

### 📋 Gestão Completa de Turmas
- Cadastro inteligente de turmas participantes
- Divisão por séries e categorias (masculino/feminino)
- Controle de jogadores e reservas
- Validação de documentação dos alunos

### ⚽ Organização de Partidas
- Sistema automático de sorteio de chaves
- Agendamento de jogos com data e local
- Controle de arbitragem e responsáveis
- Grades de horários otimizadas

### 📊 Sistema de Competição
- Pontuação com critérios claros
- Classificação em tempo real
- Histórico completo das partidas
- Estatísticas de cada turma

### 👨‍🏫 Painel de Controle
- Área administrativa para professores
- Aprovação de resultados
- Geração de relatórios
- Controle de permissões

### 📱 Para os Alunos
- Consulta de tabelas e resultados
- Próximos jogos da sua turma
- Classificação geral
- Regulamento disponível

## 🛠️ Tecnologias Utilizadas

### Backend
- **PHP 7.4+** - Lógica do servidor
- **MySQL** - Banco de dados relacional
- **Apache** - Servidor web

### Frontend
- **HTML5** - Estrutura semântica
- **CSS3 Puro** - Estilização customizada (sem frameworks!)
- **JavaScript Vanilla** - Interatividade
- **Responsive Design** - Funciona em qualquer dispositivo

### 🔧 Características Técnicas
- Arquitetura MVC (Model-View-Controller)
- CSS modular e organizado
- Código PHP limpo e comentado
- Sistema de sessões seguro
- URL amigáveis


### Pré-requisitos
```
- Servidor Apache
- PHP 7.4 ou superior
- MySQL 5.7 ou superior
- Navegador moderno
```


## 👥 Níveis de Acesso

### 👑 Administrador (Professor/Coordenador)
- Cadastro de turmas e jogadores
- Gerenciamento completo das partidas
- Validação final dos resultados
- Relatórios e estatísticas

### 🎯 Capitão de Turma
- Visualização do desempenho da sua turma
- Confirmação de presença nos jogos
